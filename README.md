# Просчёт машины

Калькулятор стоимости авто с аукциона (Copart / IAAI → Поти → РБ). Заменяет Google-таблицу «Просчет машины»: те же формулы, плюс сохранение нескольких расчётов, ссылка на расчёт и экспорт/импорт.

Без сборки и зависимостей — обычные HTML/CSS/JS.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки (в корень).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

## Где хранятся данные

В браузере (localStorage). На другом устройстве расчётов не будет — переносите кнопками «Ссылка» (один расчёт) или «Экспорт»/«Импорт» (всё сразу).

## Файлы

- `calc.js` — формулы (сборы аукциона, растаможка, итоги)
- `defaults.js` — значения по умолчанию из таблицы
- `app.js` — интерфейс и сохранение

## Обновление

После изменения JS/CSS увеличьте номер `?v=` в `index.html` и в импортах `app.js` — иначе браузеры могут до 10 минут держать старые файлы.
